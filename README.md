# Sales & Revenue Analysis Dashboard

## 📊 Project Overview

An interactive Sales & Revenue Analysis Dashboard developed using Microsoft Excel to analyze business performance and sales trends.

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Analysis

## 📌 Key Features

- Total Revenue analysis
- Total Units Sold analysis
- Total Cost analysis
- Total Profit analysis
- Country-wise analysis
- Product-wise analysis
- Monthly sales trend analysis
- Interactive filtering using Slicers

## 📂 Dataset

The dataset contains sales information including:

- Country
- Product
- Units Sold
- Revenue
- Cost
- Profit
- Date

## 🎯 Objective

To analyze sales data, identify business performance trends, and present insights through an interactive Excel dashboard.
